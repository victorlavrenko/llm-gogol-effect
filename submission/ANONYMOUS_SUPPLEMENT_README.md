# ICLR 2027 anonymous reproduction package

This archive accompanies the anonymous submission **Beyond the IKEA Effect in LLMs: Post-Completion Self-Devaluation**.

It contains frozen model outputs, prompt banks, manifests, route identifiers, derived tables, robustness and temperature-control runs, the adaptive cross-model REPLAY extension, and analysis scripts used for the reported results. The package is intended to reproduce analyses from stored outputs; exact regeneration of hosted model outputs is not guaranteed because provider routing and served model versions are external dependencies.

## Reproduce the analyses

From the archive root:

```bash
python -m pip install -r reproduction/requirements.txt
sh reproduce.sh
```

The headline six-model table is written to `results/six_model_effects.csv`. Additional deterministic outputs are generated by `reproduction/reproduce_all.py` and can be compared with the stored expected outputs.

## Anonymity

This reviewer package is generated from a scrubbed source tree. The build fails if known author-identifying names, domains, repository handles, or local user-path fragments occur in files selected for the archive. The public author repository is intentionally not linked from the anonymous manuscript or this package during double-blind review.
